## 🤖 Proyecto estrella: **ELVER**, el humanoide impreso en 3D

```console
josebarv@taller:~$ ./elver --status

  ╭─────────────────────────────────────────╮
  │   (◉ ‿ ◉)   ELVER v3  ·  ONLINE         │
  ╰─────────────────────────────────────────╯
  [ OK ] Cerebro motor ........ Arduino Mega 2560
  [ OK ] Cuello ............... 3 servos   (mira, inclina, niega)
  [ OK ] Ojos ................. 6 servos   (parpadea, guiña, te sigue)
  [ OK ] Mano ................. piedra · papel · tijera · 👍 · 👌
  [ OK ] Voz .................. ESP32-C3 XiaoZhi  →  Serial1 @115200
  [ OK ] Personalidad ......... tranquilo | curioso | somnoliento | alerta | tímido
  [WARN] Nivel de inquietud ... alto (te ha visto)

josebarv@taller:~$ █
```

Le hablas, te escucha con atención, y mientras responde mueve la cabeza, aparta la mirada y gesticula con la mano.
Todo el código, los límites de cada servo y un simulador en Python están en **[3D-Humanoid](https://github.com/Joseba-Rodriguez/3D-Humanoid)**.
